# Detection-de-Maladies-des-Plantes
Identifier les maladies des plantes via une simple photo prise avec leur smartphone. L'objectif est de créer une API capable de détecter automatiquement une feuille sur une photo Prédire si la plante est saine ou malade (et quel type de maladie) , et Enregistrer l'historique des diagnostics dans une base de données.
